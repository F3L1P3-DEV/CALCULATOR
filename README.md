# CALCULATOR
# 🧮 Calculadora en Python

Una calculadora sencilla, eficiente y fácil de usar desarrollada en Python. Este proyecto es ideal para operaciones matemáticas básicas y demuestra el uso de lógica de programación limpia y manejo de datos en Python.

---

## 🚀 Características

* **Operaciones Básicas:** Suma, resta, multiplicación y división.
* **Manejo de Errores:** Control de errores comunes, como la división por cero.
* **Interfaz Limpia:** Ejecución fluida a través de la terminal (o interfaz gráfica, si aplica).
* **Código Modular:** Estructura organizada que permite añadir nuevas funciones fácilmente.

---

## 🛠️ Requisitos

Antes de ejecutar este proyecto, asegúrate de tener instalado:

* **Python 3.x** (Recomendado)
